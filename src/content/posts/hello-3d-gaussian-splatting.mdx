## 从照片到稀疏点

一条常见的流水线是：

1. 用 COLMAP 做 SfM：提特征、匹配、增量式重建。
2. 得到每张照片的相机位姿，以及一组稀疏三维点。
3. 如果还有 LiDAR，用点云给场景一个度量尺度，再和相机对齐。

稀疏点足够做标定和初始化，但不够用来看清表面。3D Gaussian Splatting 在这些点附近放上大量各向异性高斯，靠可微光栅化把照片重新画出来。

### 相机中心

COLMAP 把外参存成四元数 `qvec` 和平移 `tvec`。相机中心在世界坐标里是 $-R^{\top}t$。

## 公式

一个三维高斯写成

$$
G(\mathbf{x})=\exp\left(-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^{\top}\Sigma^{-1}(\mathbf{x}-\boldsymbol{\mu})\right)
$$

协方差拆成旋转 $R$ 与缩放 $S$：$\Sigma = RSS^{\top}R^{\top}$。投影到图像上之后，二维协方差是 $\Sigma' = JW\Sigma W^{\top}J^{\top}$，其中 $J$ 是投影的雅可比，$W$ 是观察变换。

沿一条光线把高斯从前到后叠起来，像素颜色是

$$
C = \sum_{i=1}^{N} c_i \alpha_i \prod_{j=1}^{i-1}(1-\alpha_j)
$$

美元符号如果不是公式，写成 `\$`，避免和行内数学 `$...$` 撞车。

## 代码

下面这段只说明笔记里的代码块会高亮，不是完整的 COLMAP 读取器。

```python
import numpy as np

def camera_center(qvec: np.ndarray, tvec: np.ndarray) -> np.ndarray:
    """COLMAP qvec 的顺序是 w, x, y, z。"""
    w, x, y, z = qvec
    rot = np.array(
        [
            [1 - 2 * (y * y + z * z), 2 * (x * y - z * w), 2 * (x * z + y * w)],
            [2 * (x * y + z * w), 1 - 2 * (x * x + z * z), 2 * (y * z - x * w)],
            [2 * (x * z - y * w), 2 * (y * z + x * w), 1 - 2 * (x * x + y * y)],
        ]
    )
    return -rot.T @ tvec
```

重建命令可以记成普通的 shell 代码块：

```bash
colmap automatic_reconstructor \
  --workspace_path ./workspace \
  --image_path ./images
```
